Chrome Extension for Time Tracking and Productivity Analytics

This project is developed as part of **Task 4 of the CodTech Internship**.

## 🎯 Objective
- To understand Chrome Extension development
- To track time spent on different websites
- To analyze user productivity based on browsing behavior
- To store and retrieve usage data using a backend server

## 🛠️ Technologies Used
- JavaScript
- HTML
- CSS
- Chrome Extension (Manifest V3)
- Node.js
- Express.js

## ⚙️ Features
- Tracks time spent on each website
- Displays website usage in extension popup
- Stores browsing data locally
- Backend API to store and retrieve productivity data
- Simple and user-friendly interface
